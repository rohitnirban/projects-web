# Project Showcase

A personal project showcase website built with Next.js to display and filter my projects.

## Features

- Display projects with images, descriptions, and tags
- Filter projects by tags
- Search functionality
- Responsive design
- Links to portfolio and GitHub

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
